About This Project

This project is intended as a developer-friendly reference for Java 11. The documentation combines concise explanations, JEP references and executable examples so developers can move from concept to code quickly.

Why Java 11?

Java 11 is a Long-Term Support release and is widely used as a stable baseline for enterprise applications. It brought the standardized HTTP Client, useful API additions, modern cryptography support, Flight Recorder, single-file source launch and several JVM improvements.
