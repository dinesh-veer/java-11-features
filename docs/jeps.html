Java 11 JEP Reference

JDK Enhancement Proposals associated with the Java 11 features covered by this documentation.

What is a JEP?

JEP stands for JDK Enhancement Proposal. JEPs describe enhancements and changes to the JDK and provide the design context behind major Java releases.
