Java 11 Examples

Practical examples showing how to use the most useful Java 11 additions.

Example Catalog

The examples below are designed to be small, focused and easy to run. They can be adapted to Maven projects or individual source files.

1. HTTP Client

var client = HttpClient.newBuilder().build();
var request = HttpRequest.newBuilder()
        .uri(URI.create("https://example.com"))
        .GET()
        .build();
var response = client.send(request, HttpResponse.BodyHandlers.ofString());
System.out.println(response.statusCode());

2. var in Lambda Parameters

var values = List.of("java", "11");
values.stream()
      .map((var value) -> value.toUpperCase())
      .forEach(System.out::println);

This syntax is useful when an annotation must be applied to a lambda parameter.

3. Single-File Source Launch

// Hello.java
public class Hello {
    public static void main(String[] args) {
        System.out.println("Hello Java 11");
    }
}

# Run directly
java Hello.java

4. New String APIs

System.out.println("   Java 11   ".isBlank());
System.out.println("a\nb\nc".lines().count());
System.out.println("Java".repeat(3));
System.out.println("  Java 11  ".strip());

5. Files.writeString / readString

Path path = Path.of("demo.txt");
Files.writeString(path, "Hello Java 11");
String text = Files.readString(path);
System.out.println(text);

6. Predicate.not

var values = List.of("java", "", "11", "");
values.stream()
      .filter(Predicate.not(String::isBlank))
      .forEach(System.out::println);

7. Optional.isEmpty

Optional<String> value = Optional.empty();
if (value.isEmpty()) {
    System.out.println("No value available");
}

8. Collection Factory Methods

var list = List.of("Java", "11");
var set = Set.of("Java", "LTS");
var map = Map.of("version", 11);
