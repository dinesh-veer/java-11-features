Java 11 Installation

Set up JDK 11 and the Maven environment required to build and run the examples.

Prerequisites

  • JDK 11 installed and available on PATH
  • Maven 3.6.x or later
  • Git
  • Your preferred IDE such as IntelliJ IDEA, Eclipse or VS Code

Verify Java

java -version
javac -version

Confirm that both commands report a Java 11 toolchain.

Build with Maven

git clone https://github.com/dinesh-veer/java11-features.git
cd java11-features
mvn clean test
mvn package

Run a Single-File Example

java Hello.java

IDE Configuration

Configure the project SDK and Maven compiler level for Java 11. Make sure your IDE is not silently using a newer JDK for compilation or execution.

GitHub Pages

To publish these static files, configure GitHub Pages to deploy from the repository's /docs folder on the default branch.
