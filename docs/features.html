Java 11 Feature Overview

Java 11 is an LTS release with important changes across the Java language, standard library, HTTP stack, security providers, JVM and developer tooling.

HTTP Client

The standardized HTTP Client API supports HTTP/1.1, HTTP/2, synchronous and asynchronous requests.

JEP 321

var in Lambda Parameters

Lambda parameters can use var, enabling annotations on lambda parameters while retaining local-variable inference.

JEP 323

Single-File Launch

Run a source file directly without an explicit compilation step.

JEP 330

Flight Recorder

JFR is integrated into OpenJDK for low-overhead production diagnostics and profiling.

JEP 328

Epsilon GC

A no-op garbage collector useful for performance testing, latency experiments and short-lived workloads.

JEP 318

ZGC

A scalable low-latency experimental garbage collector introduced in JDK 11.

JEP 333

Modern Cryptography

Java 11 adds ChaCha20/Poly1305, Curve25519/448 key agreement and TLS 1.3 support.

JEP 329 / 324 / 332

Convenience APIs

New String methods, Files convenience methods and collection factory improvements make everyday coding cleaner.

JDK APIs

Nest-Based Access

The JVM gains formal nestmate support, reducing synthetic accessors for nested classes.

JEP 181

Unicode 10

Unicode 10 support expands character and script coverage available to Java applications.

JEP 327

Root Certificates

OpenJDK includes a root certificate authority set, improving out-of-the-box TLS usability.

JEP 319

Module Removals

Legacy Java EE and CORBA modules were removed from the JDK, continuing the modularization effort.
